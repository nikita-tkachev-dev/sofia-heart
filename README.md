# Sofia Heart

Однофайловая интерактивная страница на чистом HTML/CSS/JavaScript.

## Быстрый запуск через GitHub Pages

1. Создай новый GitHub repository, например `sofia-heart`.
2. Загрузи в него `index.html`.
3. Открой **Settings → Pages**.
4. В **Build and deployment** выбери **Deploy from a branch**.
5. Выбери `main` и `/ (root)`, затем **Save**.
6. GitHub даст ссылку вида:
   `https://USERNAME.github.io/sofia-heart/`

Никакого своего сервера или backend не нужно.

Текст можно поменять прямо в начале `<script>`:
`MESSAGE` и `SUBTITLE`.
